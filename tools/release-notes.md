**Changes**

- Controllers work in games after being used in the launcher (before, RetroArch never saw a pad that had been touched in the launcher)
- Controller test screen on the home screen
- Hold Start on a controller for 2 seconds to open the RetroArch menu
- Asks the TV for Game Mode (2022 and later models)
- Cores and RetroArch's files now come from this fork's GitHub Pages; TizenBrew support and the phone upload are removed

**Install**

- [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung): add `github.com/genesai/retroarch-tizen` as your own source, or install `RetroArch.wgt` below as your own `.wgt`

Cores are downloaded from https://genesai.github.io/retroarch-tizen/ on first start.
Requires a TV with Tizen 6.5+ (2022 or newer). Details in the README.
